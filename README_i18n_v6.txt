Mist Earth: Survival i18n v6

Changes:
- Expanded lang/en.js with exact translations for remaining visible Korean UI/data strings found in index.html.
- Added translations for equipment, consumables, hideout descriptions, skill grade texts, physical/mental strengths and weaknesses, manifestation descriptions, ability descriptions, Mist Gear shop dialogue, and dynamic templates.
- Language selection remains available only before SYSTEM BOOT.

Note:
This version is designed to remove Korean from player-facing English mode as much as possible from the current HTML source. If new Korean strings are added later, add them to lang/en.js using the same key/value format.
