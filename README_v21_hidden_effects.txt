[Mist Earth: Survival v21 히든 이펙트 패치]

1. 추가 내용
- 히든 선택지가 해금될 때 전용 알림이 출력됩니다.
- 히든 카드에 HIDDEN 배지와 전용 시각 효과가 적용됩니다.
- 히든 선택 시 화면 글리치/노이즈/안개/균열/블랙박스 계열 이펙트가 출력됩니다.

2. 이펙트 타입
- glitch: 화면 노이즈와 흔들림
- mist: 녹색 안개 계열 연출
- rift: 균열/좌표계 계열 연출
- blackbox: 검은 기록/블랙박스 계열 연출
- silent: 무음구역 계열 암전 연출
- blood: 봉합/출혈 계열 붉은 연출
- forbidden: 금지 지식 계열 금색 경고 연출

3. 적용 히든 예시
- 안개문 개방: rift
- 리프트 앵커: rift
- 의뢰 — 블랙박스: blackbox
- 의뢰 — 무음구역: silent
- 검은 안개 호흡: mist
- 잔향 봉합: blood
- 금지 프로토콜 / 변칙 해부학: forbidden
- 새턴 블랙링: glitch

4. 비고
- 기존 언어 시스템, 음악 플레이어, 장비상점, 히든 복합 해금 조건은 유지됩니다.
- 히든 해금 조건 자체는 v20 기준을 따릅니다.
