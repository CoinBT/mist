[v23 히든 이펙트 표시 수정]

- 히든 해금 알림은 뜨지만 화면 이펙트가 약하거나 보이지 않던 문제를 수정했습니다.
- 히든 이펙트 오버레이의 z-index를 상향했습니다.
- mix-blend-mode 의존도를 제거해 검은 배경에서도 확실히 보이도록 수정했습니다.
- 해금 시 UNKNOWN DATA UNLOCKED 중앙 연출을 추가했습니다.
- 선택 시 HIDDEN DATA SELECTED 중앙 연출을 추가했습니다.
- 화면 흔들림 효과를 body에도 적용해 체감이 더 잘 되도록 수정했습니다.
- 카테고리 진입/포인트 HUD 갱신을 거치지 않아도 click/change/keyup 이후 히든 조건을 다시 검사하도록 보강했습니다.

기존 v22의 히든 조건, 즉시 해금 알림, 장비상점, 음악 플레이어, 언어팩 구조는 유지됩니다.
