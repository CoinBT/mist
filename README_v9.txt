Mist Earth: Survival i18n v9

Changes from v8:
- Music track titles are no longer translated, romanized, or uppercased.
- Track list is excluded from automatic i18n replacement.
- Music titles are shown as the original filename without extension.
- Play/Pause button now syncs with actual audio state.
  - Paused: ▶
  - Playing: ⏸
- Initial BGM volume and slider value are set to 50%.
- Added extra English dictionary entries for remaining Korean UI labels/placeholders.
- Music/List folder support from v7/v8 is preserved.

Required music folder example:
Music/List/Dust.mp3
Music/List/Rust Orchard.mp3
Music/List/wispering.mp3
Music/List/モノクロの劇場.mp3
Music/List/마법소녀 데스매치 ED - 灰色の夜.mp3
Music/List/마법소녀 데스매치 OST.mp3
