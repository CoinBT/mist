# v26 히든 기술 선택 방식 수정

## 변경 내용

- 히든 기술은 이제 등급 선택창을 열지 않고, 일반 선택지처럼 바로 선택/해제됩니다.
- 히든 기술은 별도의 등급 이미지 `001.png ~ 006.png`를 요구하지 않습니다.
- 히든 기술은 기존에 지정한 대표 이미지 경로만 사용합니다.

## 적용 대상

- 금지 프로토콜
- 잔향 추적
- 변칙 해부학

## 이미지 경로

히든 기술 대표 이미지는 아래 경로만 사용합니다.

```text
img_cho/08/H_001/main.png  ← 금지 프로토콜
img_cho/08/H_002/main.png  ← 잔향 추적
img_cho/08/H_003/main.png  ← 변칙 해부학
```

아래 같은 등급별 이미지는 더 이상 필요하지 않습니다.

```text
img_cho/08/H_001/001.png
img_cho/08/H_001/002.png
...
img_cho/08/H_001/006.png
```

## 유지 사항

- 히든 해금 조건은 기존 v24/v25 기준 유지
- 히든 해금 알림/이펙트 유지
- 일반 기술은 기존처럼 등급 선택 방식 유지
- 히든 출신지/히든 이능/히든 미스트기어 이미지 경로 유지
