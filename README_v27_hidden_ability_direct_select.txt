# v27 히든 이능 선택 방식 수정

## 변경 내용

- 히든 이능은 이제 등급 선택창을 열지 않고, 일반 선택지처럼 바로 선택/해제됩니다.
- 히든 이능은 별도의 등급 개념을 사용하지 않습니다.
- 히든 이능은 기존에 지정한 대표 이미지 경로만 사용합니다.

## 적용 대상

- 안개문 개방
- 잔향 봉합
- 검은 안개 호흡

## 이미지 경로

히든 이능 대표 이미지는 아래 경로만 사용합니다.

```text
img_cho/09/H_001/main.png  ← 안개문 개방
img_cho/09/H_002/main.png  ← 잔향 봉합
img_cho/09/H_003/main.png  ← 검은 안개 호흡
```

## 유지 사항

- 히든 해금 조건은 기존 v24~v26 기준 유지
- 히든 해금 알림/이펙트 유지
- 일반 이능은 기존처럼 등급 선택 방식 유지
- 히든 출신지/히든 기술/히든 미스트기어 이미지 경로 유지
