v16 Equipment Shop Remodel

- Weapon shop split into Primary Weapon, Secondary Weapon, and Melee Weapon.
- Primary/Secondary weapons now separate Conventional Firearms and Mist Firearms.
- Conventional firearms use credits only and can select Lead / Incendiary / Armor-Piercing rounds.
- Mist firearms cost more credits and can also select Mist / Aberration rounds.
- Melee weapons now select one of four materials: Common Steel / Reinforced Steel / Mist Alloy / Mist Steel.
- Consumable mechanics remain quantity-based, but the UI has been visually improved.
- English language pack updated with new equipment terms.

v16 장비상점 리모델링

변경사항:
- 무기 상점을 주무기, 보조무기, 근접무기로 분리했습니다.
- 주무기/보조무기는 일반 화기와 미스트 화기로 구분됩니다.
- 일반 화기는 크레딧만 소모하며 납탄 / 소이탄 / 철갑탄을 선택할 수 있습니다.
- 미스트 화기는 더 많은 크레딧을 소모하며 미스트탄 / 괴이탄도 선택할 수 있습니다.
- 근접무기는 일반강철 / 강화강철 / 미스트 합금 / 미스트 스틸 중 하나의 재질을 선택합니다.
- 소모품 메커니즘은 기존 수량 기반 구조를 유지하되, UI를 더 보기 좋게 개선했습니다.
- 새 장비 용어에 대한 영어 번역을 추가했습니다.
