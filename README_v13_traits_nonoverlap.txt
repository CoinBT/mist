Mist Earth: Survival — v13 Traits Non-overlap Patch

Changes:
- Removed all v12 added physical/mental strength/weakness entries.
- Added 12 new entries each to:
  * Physical Strengths
  * Physical Weaknesses
  * Mental Strengths
  * Mental Weaknesses
- New entries were designed to avoid direct overlap with the user's existing items such as night vision, balance, endurance, hand dexterity, fear resistance, memory, lie detection, and similar categories.
- Added English localization entries for all new v13 trait names/descriptions.
- Preserved previous v10 balance patch, v9 music-player fixes, and v11 body/mental ability additions.
