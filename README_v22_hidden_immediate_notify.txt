Mist Earth: Survival v22 - 히든 즉시 알림 패치

[변경사항]
- 기존에는 히든 조건을 만족해도 해당 카테고리 화면을 열어야 해금 알림이 출력되던 문제를 수정했습니다.
- 이제 포인트, 오염도, 미스트, 선택지 상태가 변경될 때마다 전체 히든 조건을 자동 검사합니다.
- 조건을 만족한 히든은 카테고리에 들어가지 않아도 즉시 해금 알림과 이펙트가 출력됩니다.
- 기존 HIDDEN 배지, 히든 선택 이펙트, 상태창 특수 표시 구조는 유지됩니다.
- 이미 한 번 알림이 출력된 히든은 중복 알림이 반복되지 않습니다.

[적용 방식]
- updatePointHUD() 이후 자동으로 히든 해금 검사 실행
- 상태 태그 전체 갱신 이후에도 보조 검사 실행
- categoryData / questData / mistgearData 안의 hidden 항목을 전체 스캔

[주의]
- 히든 조건 자체는 v20/v21 기준을 유지합니다.
- 이번 패치는 해금 조건 변경이 아니라 알림 타이밍 개선 패치입니다.
